# Marca SELL — guia rápido

## Logo

O **S** é um casco seccionado: a meia-nau superior, a **linha d'água em onda** em âmbar e a meia-nau inferior. As letras **E-L-L** usam o mesmo traço, com terminais retos, para dar a precisão de um desenho técnico. A leitura é engenharia (geometria) aplicada ao mar (onda).

Arquivos em `public/brand/`:

| Arquivo | Uso |
|---|---|
| `sell-wordmark.svg` / `sell-mark.svg` | fundo claro |
| `sell-white-wordmark.svg` / `sell-white-mark.svg` | fundo escuro |
| `sell-mono-*.svg` | 1 cor (carimbo, gravação, fax) |
| `src/app/icon.svg` | favicon / app icon |

Área de proteção: altura do "E" ao redor. Tamanho mínimo: wordmark com 18 px de altura, símbolo com 16 px.

## Paleta

| Token | Hex | Uso |
|---|---|---|
| abyss | `#07111C` | fundos escuros, texto sobre âmbar |
| deep | `#0C1B2B` | superfícies escuras secundárias |
| hull | `#13263A` | hover e gradientes escuros |
| tide | `#2F6FA3` | ícones, realces e dados |
| fog | `#EEF1F4` | fundo claro principal |
| paper | `#FFFFFF` | cards |
| ink | `#0A1520` | texto principal |
| muted | `#5F6B77` | texto secundário |
| **signal** | `#F2A900` | âmbar de sinalização marítima: onda do logo, CTA, foco. Usar com moderação e nunca como cor de texto sobre fundo claro. |

O âmbar vem do amarelo da marca antiga e foi refinado para o tom de sinalização náutica. O azul-marinho foi aprofundado.

## Tipografia

- **Geist** (títulos e texto): títulos em peso 400 com tracking negativo.
- **Fragment Mono** (rótulos/eyebrows): caixa alta, tracking 0,14em.
